### 3. 📁 정적 파일 서빙 설정 (FastAPI)

#### ✅ 완료된 작업
- **FastAPI StaticFiles 마운트**
  - `uploads` 폴더를 `/uploads` 경로로 서빙
  - 정비명세서 이미지 직접 접근 가능

#### 🔧 구현 코드 (main.py)
```python
from fastapi.staticfiles import StaticFiles
import os

# 정적 파일 서빙 설정
uploads_path = os.path.join(os.path.dirname(os.path.dirname(__file__)), "uploads")
if os.path.exists(uploads_path):
    app.mount("/uploads", StaticFiles(directory=uploads_path), name="uploads")
```

#### 🌐 접근 가능한 URL 형식
```
http://localhost:8000/uploads/maintenance_images/[파일명].jpg
```

### 4. 🔗 첨부파일 URL 생성 로직 개선 (history.py)

#### ✅ 완료된 작업
- **Windows 경로 처리 개선**
  - `os.path.basename()` 사용으로 크로스 플랫폼 호환성 확보
  - DB 경로에서 `uploads/` 이후 상대 경로 추출
  - `maintenance_images` 하위 폴더 경로 포함

#### 🔧 구현 로직
```python
attachment = cursor.fetchone()
attachment_url = None
if attachment and attachment['file_path']:
    import os
    # file_path에서 uploads 이후 경로 추출
    file_path = attachment['file_path'].replace('\\', '/')
    if 'uploads/' in file_path:
        relative_path = file_path.split('uploads/')[-1]
        attachment_url = f"http://localhost:8000/uploads/{relative_path}"
    else:
        filename = os.path.basename(attachment['file_path'])
        attachment_url = f"http://localhost:8000/uploads/maintenance_images/{filename}"
```

## 🐛 해결된 주요 이슈

### Issue #1: TypeError - toLocaleString()
**문제**: `record.cost`가 `undefined`일 때 에러 발생  
**해결**: 안전한 접근 패턴 적용
```javascript
(record.cost || record.total_cost || 0).toLocaleString()
```

### Issue #2: API 404 에러 (정비 이력 삭제)
**문제**: `/api/v1/maintenance/{id}` 엔드포인트 미존재  
**해결**: `/api/v1/history/{id}`로 엔드포인트 수정

### Issue #3: 명세서 보기 버튼 미표시
**문제**: `attachment_url`이 API 응답에 포함되지 않음  
**해결**: `history.py`에 첨부파일 조회 로직 추가

### Issue #4: 이미지 로드 실패 (404)
**문제**: 정적 파일 서빙 미설정  
**해결**: FastAPI `StaticFiles` 마운트 추가

### Issue #5: 이미지 경로 오류
**문제**: `maintenance_images` 하위 폴더 경로 누락  
**해결**: Windows 경로 처리 로직 개선 (`os.path.basename()` 사용)
