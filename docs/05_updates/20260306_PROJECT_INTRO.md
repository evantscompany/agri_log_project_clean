1. 배경 및 문제 의식 (Problem Statement)1.1 농기계 산업의 현재 문제정비 이력 관리의 부재: 대다수의 농민이 정비 명세서를 종이 형태로 보관하거나 분실하여, 기계의 정확한 상태를 증명하기 어려움.정보의 비대칭성: 중고 거래 시 구매자는 관리 이력을 알 수 없고, 판매자는 적정 가격 산정 기준이 부족하여 불신이 발생함.유지보수 전문성 결여: 복잡한 부품명과 정비 내용을 이해하기 어려워 예방 정비 타이밍을 놓치고 과도한 수리비가 지출됨.1.2 Agri Log가 해결하고자 하는 문제데이터 디지털화: 수기/종이 문서를 사진 한 장으로 데이터베이스화하여 관리 편의성 증대.자산 가치의 투명화: 객관적 정비 데이터와 머신러닝 모델을 결합하여 투명하고 합리적인 중고 시세 형성.스마트 가이드 제공: AI 분석을 통해 기술 용어를 쉽게 풀이하고 계통별 진단을 제공하여 농기계 수명 연장.2. 시스템 아키텍처 및 기술 스택2.1 전용 스택 (Tech Stack)Frontend: React 18, Vite, TailwindCSS, Axios, Lucide ReactBackend: FastAPI (Python), Uvicorn, PydanticDatabase: MySQL 8.0 (9개 테이블 정규화 구조)AI/ML: Google Vision API (OCR), Scikit-learn (RandomForest/Linear Regression), Joblib2.2 데이터베이스 주요 구조마스터 정보: machine_master, manufacturer_codes, category_codes개별 기기: machine_instance (기대번호별 실시간 상태 및 가동시간)이력 관리: maintenance_log, maintenance_detail, maintenance_attachment부품 데이터: part_list, v_part_list_all3. 핵심 구현 기능 (Core Features)3.1 OCR 기반 정비 이력 자동화데이터 자동 추출: Google Vision API를 통해 명세서 내 기대번호(VIN), 모델명, 총 비용, 정비업체명을 자동 인식.지능형 파싱: 다양한 영수증 포맷 및 한글 인코딩 문제를 해결하는 정규식(Regex) 기반 파서 적용.3.2 농기계 식별 및 VIN 파싱 시스템제조사 규칙 분석: 대동(Daedong) 등 주요 제조사의 기대번호 규칙을 분석하여 기종, 모델, 제작 연도 자동 식별.데이터 무결성: 동일 기대번호 중복 등록 검증 로직을 통한 데이터 신뢰도 확보.3.3 머신러닝 기반 중고 시세 예측가격 예측 모델: 학습된 모델(daedong_model.pkl)을 통해 기대번호와 가동시간 기반 예상 시세 산출.신뢰도 시스템: 예측 결과와 함께 데이터 품질에 따른 신뢰도 등급(높음/보통/낮음) 제공.3.4 AI 전문가 소견 (Maintenance Insight)계통별 기술 분석: 교체 부품 데이터를 분석하여 엔진, 유압 등 주요 계통의 상태를 전문가 관점에서 진단.예방 정비 제안: 분석 리포트를 통해 잠재적 결함 가능성을 안내하고 적정 정비 시기 가이드 제공.4. 개발 완료 및 해결 사항 (2026.03.16 기준)구분주요 해결 내용Backend/api/v1/history 엔드포인트 통합, OS별 경로 호환성 확보, 정적 파일 서빙 설정Frontend정비명세서 이미지 모달 구현, 안전한 데이터 렌더링 적용, AI 소견 UI 고도화Data기존 테스트 데이터 정제 및 service_company 컬럼 마이그레이션 완료MLVIN 기반 모델명 자동 매칭 및 중고 시세 예측 연동 완료5. 향후 로드맵 (Roadmap)단기: 이미지 Lazy Loading 및 썸네일 생성 기능을 통한 성능 최적화.중기: LS, TYM 등 다중 제조사 지원 확대 및 비용 추이 시각화 차트 도입.장기: PWA 기술 기반 앱 설치 지원 및 정비 주기 자동 알림(Push) 서비스 구현.
