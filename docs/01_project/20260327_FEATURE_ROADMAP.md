# 🛣️ 기능 개발 로드맵

## 📋 개요

농기계 데이터 이력관리 플랫폼에 추가해야 할 기능들을 우선순위별로 정리한 로드맵입니다. 현재 구현된 기능와 앞으로 개발할 기능들을 체계적으로 관리할 수 있습니다.

---

## 🎯 현재 구현된 기능

### ✅ 완료 (v1.0)
- **농기계 관리**: 등록, 조회, 수정, 삭제
- **정비 이력 관리**: CRUD 기능
- **OCR 스캐너**: 정비 명세서 스캔 및 데이터 추출
- **가격 예측**: 머신러닝 기반 예측 모델
- **AI 전문가**: GPT 기반 상담 시스템
- **부품 관리**: 부품 목록 관리
- **모바일 앱**: 소유자/정비업체 모드
- **웹 프론트엔드**: React 기반 관리자 페이지

## 🚀 단기 개발 계획 (1-3개월)

### 🔥 필수 기능 (P0)

#### 1. 🔐 인증 및 권한 관리 시스템
**우선순위**: 🔥 최고
**예상 기간**: 2주
**기능 상세**:
- JWT 토큰 기반 인증
- 역할 기반 접근 제어 (RBAC)
  - 소유자 (Owner)
  - 정비업체 (Mechanic)
  - 관리자 (Admin)
  - 제조사 (Manufacturer)
- 소셜 로그인 (Google, Naver)
- 다중 팩터 인증 (MFA)

**API 엔드포인트**:
```
POST /api/v1/auth/login
POST /api/v1/auth/logout
POST /api/v1/auth/refresh
GET /api/v1/auth/profile
PUT /api/v1/auth/profile
```

## 🛠️ 기술 부채 해결

### 🔧 리팩토링 필요 사항

#### 1. 코드 품질 개선
- **테스트 커버리지**: 현재 30% → 목표 80%
- **ESLint/Prettier**: 코드 스타일 통일
- **타입스크립트**: JavaScript → TypeScript 마이그레이션
- **에러 핸들링**: 통합 에러 처리 시스템

#### 2. 성능 최적화
- **API 응답 속도**: 현재 200ms → 목표 50ms
- **데이터베이스 쿼리**: 인덱스 최적화
- **이미지 처리**: CDN 도입
- **캐싱 전략**: Redis 도입

#### 3. 보안 강화
- **입력 검증**: 모든 API 엔드포인트
- **SQL 인젝션**: Prepared Statement 적용
- **XSS 방지**: CSP 헤더 추가
- **Rate Limiting**: API 요청 제한
